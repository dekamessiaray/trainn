# Deka — Personal Portfolio

Responsive personal portfolio with an iOS-inspired glassmorphism interface.

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Customize before publishing
- Replace `profile.png` with your preferred portrait.
- Update the LinkedIn URLs in `index.html` to your actual profile URL (currently links to LinkedIn's homepage).
- Add the exact competition name, organizer, date, and certificate link to the achievements section so the details are accurate.
- Update Instagram and the introduction if your focus changes.

## Files
- `index.html` — semantic page content and links
- `style.css` — responsive styling, glass surfaces, motion, and mobile layout
- `script.js` — dynamic year and subtle reveal effects
