# Deka Messi Araya — Liquid Glass Portfolio

A responsive personal portfolio inspired by Apple's glass UI language: translucent surfaces, ambient gradients, fine borders, soft shadows, and subtle motion. Built with plain HTML, CSS, and JavaScript — no framework or build step required.

## Files
- `index.html` — semantic page structure and portfolio content
- `style.css` — glassmorphism design system, responsive layout, themes, and animation
- `script.js` — appearance toggle, mobile navigation, scroll reveal, active navigation, progress indicator, and achievement filters
- `profile.png` — profile photo from the original repository
- `favicon.svg` — lightweight site icon

## Run locally
Open `index.html` in a browser, or use VS Code with Live Server. Internet access is only needed for the optional Google Fonts and outbound LinkedIn/Instagram links. System font fallbacks are configured.

## Personal details and accuracy
Profile roles, school, interests, credentials, and selected awards were adapted from the public LinkedIn profile linked throughout the website. Project summaries are clearly framed as an initiative, a competition concept, or an early-stage project where appropriate. Please review all dates and wording before publishing in case your LinkedIn profile has changed.

## Customize
- Update the content in `index.html`.
- Change colors and surfaces at the top of `style.css` under `:root` and `html[data-theme="dark"]`.
- Add projects and awards by duplicating the relevant card pattern in `index.html`.

Includes keyboard focus styles, skip link, mobile menu labels, achievement filter states, and reduced-motion support.
